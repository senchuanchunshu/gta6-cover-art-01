Vice Cover Studio — an offline, multi-panel GTA-style cover art maker. Pick one of three panel layouts and three colour grades, drop your own photos into the panels (or use the bundled samples), drag to crop, scroll to zoom, write a bold double-stroke title, and export a PNG in 1080×1080, 1080×1350 or 1920×1080. Every sunset, skyline, palm and grain effect is drawn in code; nothing is borrowed from Rockstar.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — no build step, no network requests, your photos never leave your machine.
